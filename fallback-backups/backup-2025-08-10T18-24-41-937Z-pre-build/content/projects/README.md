# Projects Collection Guide

This directory contains project portfolio content managed through Decap CMS. Each project is stored as a Markdown file with YAML frontmatter containing structured data.

## Required Fields

The following fields are required for all projects:

- **Title**: Project name or title
- **Category**: Must be one of: Residential, Commercial, Industrial, Infrastructure
- **Status**: Must be one of: Planning, In Progress, Completed, On Hold
- **Location**: Project location (city, area, or full address)
- **Short Description**: Brief description for project listings
- **Main Image**: Primary project image for showcase
- **Body**: Detailed project description in Markdown format

## Optional Fields

### Project Details
- **Completion Date**: Date when project was completed (for completed projects)
- **Duration**: Project timeline (e.g., "6 months", "1 year")
- **Budget**: Project budget or cost estimate

### Images
- **Gallery**: Additional project images beyond the main image

### Specifications
- **Area**: Total project area (e.g., "3,500 sq ft")
- **Bedrooms**: Number of bedrooms (for residential projects)
- **Bathrooms**: Number of bathrooms/restrooms
- **Floors**: Number of floors/stories
- **Materials**: List of key construction materials

### Additional Information
- **Features**: List of notable project features
- **Timeline**: Detailed project phases with duration and status
- **Team**: Project manager and architect information
- **Client**: Client information, testimonials, and ratings
- **Featured**: Whether to display prominently on homepage

## File Naming

Project files should use descriptive, URL-friendly names:
- Good: `luxury-villa-dar-es-salaam.md`
- Good: `commercial-office-mikocheni.md`
- Avoid: `project1.md`, `new project.md`

## Image Guidelines

### Main Image
- Should be high-quality and representative of the project
- Recommended size: 1200x800 pixels or larger
- Formats: JPG, PNG, WebP

### Gallery Images
- Should showcase different aspects of the project
- Consistent aspect ratio recommended
- Optimize for web to reduce file size

## Content Writing Tips

### Short Description
- Keep to 1-2 sentences
- Focus on key project highlights
- Used in project listings and previews

### Body Content
- Use Markdown formatting for structure
- Include project overview, key features, and outcomes
- Add sections for different aspects (architecture, construction, client satisfaction)
- Use headers (##, ###) to organize content

## Project Categories

### Residential
- Single-family homes
- Apartments and condominiums
- Residential complexes
- Housing developments

### Commercial
- Office buildings
- Retail spaces
- Hotels and hospitality
- Mixed-use developments

### Industrial
- Factories and manufacturing facilities
- Warehouses and distribution centers
- Industrial complexes

### Infrastructure
- Roads and bridges
- Water treatment facilities
- Public buildings
- Utilities and services

## Status Guidelines

- **Planning**: Project is in design/planning phase
- **In Progress**: Active construction underway
- **Completed**: Project finished and delivered
- **On Hold**: Project temporarily suspended

## Best Practices

1. **Consistent Data**: Use consistent formats for dates, measurements, and currency
2. **Quality Images**: Always use high-quality, professional project photos
3. **Accurate Information**: Ensure all project details are accurate and up-to-date
4. **Regular Updates**: Update project status and information as work progresses
5. **Client Privacy**: Only include client information with proper consent

## Troubleshooting

### Common Issues
- **Missing Required Fields**: Ensure all required fields are filled before saving
- **Image Upload Errors**: Check file size and format requirements
- **Validation Errors**: Review field requirements and data types

### Getting Help
- Check field hints in the CMS interface
- Review existing project examples
- Contact the development team for technical issues

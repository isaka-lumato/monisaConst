# Minimal Project Test

This is a test project with only the required fields filled in to validate the CMS configuration.

The project demonstrates that the following fields are properly marked as required:
- Title
- Category
- Status
- Location
- Short Description
- Main Image
- Body content

All other fields are optional and can be left empty without causing validation errors.
